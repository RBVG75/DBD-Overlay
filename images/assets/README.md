# Stream theme assets

Replace the placeholder paths declared by each JSON file in `../themes/` with
your own transparent PNG/SVG files. The application never generates or embeds
character artwork.

Expected paths:

```text
/assets/<theme>/main.png
/assets/<theme>/icon.svg
/assets/<theme>/alert-icon.svg
```

Create the character folders here when adding the real assets. The JSON routes
are intentionally valid placeholders until those files are supplied.
